WAT WEB

Yes this is a web (website page) all about wats!

WATS (World Acorn Triplets) is an unofficial unit of power. The way it works is kind of silly, but it measures how many joules would be released if you where to burn all the calories in 3 acorns (usually 110 Kcal).

For example, 1 WAT is 460.24 kilojoules. 1 kilowat is 1380.72 kilojoules. and so on. There will be an added calculator soon but AIRN just wait.
